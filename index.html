Mercury.

I'm building Mercury, a desktop AI coding assistant that I want to make a better alternative to Claude Code and Codex for the way I work! My focus is local model integration and live plugin and skill lookup, alongside project chat, planning, and tools for reading, editing, and testing code.

The goal is to let you choose a model running on your own machine and look up relevant plugins and skills as you work. I want it to be easy to find the tools a project needs and put them to use!

Work in progress — no interactive demo yet.
